CampusAuction Sepolia 部署助手

使用 MetaMask 确认交易，部署 P3 交付的两个合约。页面仅连接 Sepolia 测试网，不收集或存储私钥。

部署参数

起拍价 0.01 ETH · 最低价 0.002 ETH · 每 30 秒降价 0.001 ETH · 持续 900 秒（15 分钟）

金额均为测试 ETH。部署后保持待启动，直到现场演示时再启动拍卖。

1 连接并检查钱包

请在装有 MetaMask 的浏览器中打开本页，并切换至 Sepolia。测试 ETH 可从以太坊官方列出的水龙头免费领取。

尚未连接

2 按顺序确认交易

  1. 部署 CampusSouvenirNFT
  2. 向当前钱包铸造 Token ID 0
  3. 部署 CampusAuction，当前钱包作为卖方
  4. 授权拍卖合约管理该 NFT

每次点击只发送一步交易，先核对钱包中的网络和交易信息，再确认。只读查询与 Gas 估算使用 Sepolia 公共 RPC；交易仍由 MetaMask 签名发送，Gas 上限按估算值增加 20% 余量。页面记录公开的交易哈希，可在刷新后继续。

已有 NFT #0 已返还当前卖方，可复用它，只需部署新的拍卖合约并重新授权，省去重复部署 NFT 和铸造。

旧拍卖结束后，请先点击“创建新一轮拍卖”。旧地址与交易记录会保留，不会被当成新的拍卖。新实例默认持续 15 分钟。

等待连接…

3 保存证据并打开前端

打开拍卖前端 →

同一浏览器、同一地址下，前端会自动读取部署配置。换浏览器时需重新连接部署钱包，并在本页恢复配置或手动将配置写入 app.js。

源码验证用文件：Solidity Standard JSON Input。选择编译器 0.8.28，设置以文件内 settings 为准。实际链上部署后还需在 Sepolia Etherscan 完成源码验证。
